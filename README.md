# Aurelia

**End-to-End Trip Booking and Assistant System**

Aurelia is a travel planning platform that helps users plan trips from start to finish. It combines a modern frontend with a backend service to support trip discovery, itinerary planning, and a smooth booking-style experience.

## About the Project

Aurelia is designed to simplify trip planning by bringing everything into one place. Instead of manually searching for places, building an itinerary, and managing travel details separately, users can use Aurelia to organize their trip in a more guided and efficient way.

The project is structured into:

- `frontend` — user interface built with modern web technologies
- `backend` — server-side logic and data handling

## Features

- End-to-end trip planning flow
- Assistant-style travel experience
- Separate frontend and backend architecture
- Clean and scalable project structure
- Built for future integration of smarter planning and booking features
