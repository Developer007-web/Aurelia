# ✈️ Aurelia

> **Luxury AI-Powered End-to-End Travel Planning Platform**

Aurelia is an intelligent travel planning platform that creates complete, personalized trips in seconds. Instead of spending hours researching destinations, hotels, attractions, and transport, users simply enter their travel preferences, and Aurelia generates a complete itinerary tailored to their needs.

Whether you're planning a **solo adventure, family vacation, couple's getaway, or friends' trip**, Aurelia provides a seamless planning experience with the power of AI.

---

## 🌟 Features

- 🗺️ Personalized AI-generated travel itineraries
- 💰 Budget-based trip recommendations
- 👨‍👩‍👧‍👦 Support for Solo, Couple, Family & Friends trips
- 📍 Destination recommendations
- 🏨 Hotel suggestions
- 🍽️ Restaurant recommendations
- 🎡 Tourist attractions
- 🚖 Local transportation guidance
- 📅 Day-wise itinerary generation
- 📱 Modern responsive UI
- ⚡ Fast and scalable architecture

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/Developer007-web/Aurelia.git

cd Aurelia
```

---

## Install Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## Install Backend

```bash
cd backend
npm install
npm start
```

---

# 🎯 How It Works

1. Select trip type (Solo, Couple, Family, Friends)
2. Enter travel destination
3. Select travel dates
4. Choose your budget
5. Add preferences and interests
6. Aurelia generates a personalized itinerary
7. Explore hotels, attractions, food, and transport recommendations

# ⭐ Why Aurelia?

Planning a trip usually requires switching between multiple websites for hotels, attractions, restaurants, transportation, and budgeting.

Aurelia simplifies this by bringing everything together into one AI-powered platform that creates a complete travel plan in seconds, helping users save time while enjoying a premium travel planning experience.
